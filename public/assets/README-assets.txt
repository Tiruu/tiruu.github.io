Assets de la refonte

Le site fonctionne immédiatement avec les SVG de démonstration fournis.

Pour conserver les visuels historiques de ton portfolio actuel, copie tes assets existants dans
public/images/ puis remplace les chemins dans src/data.ts et, si tu le souhaites, le portrait dans
src/App.tsx.

Assets historiques disponibles dans le repo actuel :
- images/icons/lino-pfp.webp
- images/thumbnails/*
- images/projects/udsp89/*
- images/graphics/*

Je n'ai volontairement pas inventé de nouvelles photos de projets : les SVG servent de placeholders
propres jusqu'à ce que les visuels originaux soient copiés.
